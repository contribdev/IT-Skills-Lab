# Материалы по неделям

Развёрнутые методички к [общему плану](../devops-roadmap-26-weeks.md). Каждый файл — самодостаточный материал на одну неделю: конспект теории, задания с командами, разбор типовых ошибок, вопросы для самопроверки.

## Как работать с файлом недели

1. **Понедельник** — прочитай раздел «Теория» целиком, не выполняя заданий. Цель — построить карту, а не запомнить.
2. **Вт–Чт** — задания 1–3 в порядке следования. Каждое задание завершается коммитом в репозиторий.
3. **Сб (длинный блок)** — задания 4+ и раздел «Ломаем специально».
4. **Вс (30 мин)** — вопросы для самопроверки вслух, заполнение журнала, отметка чек-листа.

Если задание не идёт больше 90 минут — помечай `TODO`, иди дальше. Возвращаться будешь на неделе 8 (troubleshooting) и в месяце 6.

## Правило журнала

После каждой недели в `notes/week-NN.md` фиксируй строго три вещи:

```markdown
## Что сломалось
<симптом> → <как диагностировал> → <причина> → <решение>

## Что удивило
<то, что оказалось не так, как ты думал>

## Что осталось непонятным
<явно, чтобы вернуться>
```

Раздел «Что сломалось» — это твой будущий ответ на собеседовании. Он ценнее конспектов.
