Argo CD — это декларативный инструмент непрерывной доставки (Continuous Delivery) для Kubernetes, реализующий паттерн GitOps .

Ключевая идея GitOps: Git-репозиторий является единственным источником правды для описания желаемого состояния приложения. Всё, что должно быть в кластере, описано в Git. Argo CD следит за этим описанием и автоматически приводит кластер к нужному состоянию .

Зачем это нужно:

Аудит: каждое изменение проходит через Git, видно кто, что и когда поменял.
Автоматизация: не нужно вручную применять kubectl apply — Argo CD сделает это сам.
Самовосстановление: если кто-то вручную изменил ресурс в кластере, Argo CD вернёт его к состоянию из Git 

Argo CD работает как Kubernetes-контроллер, который постоянно сравнивает два состояния:
Желаемое состояние (Desired State) — то, что описано в Git-репозитории (YAML, Helm, Kustomize).
Текущее состояние (Live State) — то, что реально работает в кластере.

Если они расходятся — приложение помечается как OutOfSync. Argo CD может автоматически или вручную синхронизировать кластер с Git .
Цикл работы:

Git (желаемое)  ←→  Argo CD (сравнивает)  ←→  Кластер (текущее)
                         │
                         ├── Synced (всё совпадает)
                         └── OutOfSync (есть расхождения)
